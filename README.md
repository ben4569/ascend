# Ascend

Ascend is an AI-powered personal growth platform.

The long-term goal is to turn a user's ambitions into:

1. A personalized understanding of their situation
2. A structured roadmap
3. Daily actionable tasks
4. Progress tracking
5. Gamification
6. AI-powered adaptation and coaching

---

# Phase 1

Phase 1 establishes the backend foundation.

Included:

- Flask application
- PostgreSQL connection pool
- Database schema
- Environment configuration
- Basic validation utilities
- Logging
- Error pages
- Landing page
- Health endpoint
- Basic tests

Authentication and AI functionality are intentionally not included yet.

---

# Requirements

Python 3.11+

PostgreSQL 14+
